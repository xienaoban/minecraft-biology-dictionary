# Changelog

All notable changes to Biology Dictionary will be documented in this file.

## Release

### Added

- Entity search can now browse the entity classifications: the search screen offers one bookmark per classification, showing its category tree with entity counts and descriptions, plus a preview button that lists the entities of a category
- Categories can now be used as search filters: click a category to add or remove it, the selected categories are listed as removable chips below the search box, several categories are combined, and a category also matches the entities of its subcategories

### Changed

- Tooltips now indicate the current state (active search field, discovery filter mode) instead of describing the click action
- Refreshed the icon sheet: new search button, category preview button and chip art, plus a shorter progress bar tile
- Search filter chips use the new chip background with white text
- Tooltips across the book are rendered through one shared helper, so they are placed consistently
