# Changelog

All notable changes to Biology Dictionary will be documented in this file.

## Release

### Added

- Akashic Tome compatibility: the Biology Dictionary book can now be stored in the Akashic Tome, and the hotkey detects it inside the tome

### Changed

- Cleaned up compatibility package and class names

### Fixed

- Zero-count item stacks are no longer treated as the Biology Dictionary book
- Entity models in the dictionary no longer twitch or drift into their airborne pose when animation resource packs are installed
- The first-person shoulder parrot no longer flaps its wings or jitters its head
