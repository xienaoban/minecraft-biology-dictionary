# Changelog

All notable changes to Biology Dictionary will be documented in this file.

## Release

### Added

- A search entry beside the book, opening a new search screen
- Simple keyword search: whitespace separated keywords, matched against the entity name and the entity id
- Matching options of the search: full match, case sensitive and regex
- The search results keep the tool bars of the entity list: discovery progress, "only discovered entities", multi selection and add to blacklist
- A hint when a search finds no entity, or when every match is still undiscovered

### Changed

- Extract the entity category model out of `EntityManager` into the new `EntityClassificationManager`
