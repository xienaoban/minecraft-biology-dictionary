# Changelog

All notable changes to Biology Dictionary will be documented in this file.

## Release

### Added

- New players receive a Biology Dictionary item when joining the world for the first time (server config `giveBookOnFirstJoin`, default on).

### Changed

- The No-AI skill tooltip now explains cost scaling by hostile/neutral/friendly, and friendly mobs no longer waive the experience level requirement.
- The range for opening and keeping the entity detail screen is now a server config (`entityDetailScreenRange`), default 10m, max 1024m.

### Fixed

- Spyglass no longer shows the discovery progress bar or completion animation when observing blacklisted entities.
