# 按版本

## v0.7 — Architectury 双平台 + 基础设施（v0.7.0~v0.7.5）

✨ 新增
- 双平台架构落地：把 Fabric-only 的 common/ 迁入 Architectury common/ 并改名 platform/ 包；用 @ExpectPlatform + fabric/、neoforge/ 两套 *Impl 实现双端，NeoForge 入口 BiologyDictionaryNeoForge(Client/Server) 跑通。
- SkillCost 扩展 health / satiety 两类消耗（ofHealth/ofSatiety，分别走 EntityUtils.hurt 与 PlayerUtils.consumeSatiety）；check/consume 改收 ClientContext/ServerContext record。此时属前置能力，尚无 skill 调用。
- Compat 模块：CompatibilityManager 启动时 isModLoaded 检测 Modern UI，命中则关掉自研高级文字渲染走原版。
- 高级文字渲染基础设施：GuiTextRenderStateIMixin/GuiGraphicsIMixin 用 @Accessor 暴露 MC 新渲染管线私有字段，配合 ScreenConsts（0.5x 缩放文字的亚像素垂直偏移）。
- testServer 测试体系 + AST/字节码工具（AstParser、BytecodeDecompiler、NbtTagCollector）自动提取原版 NBT 属性。

🔧 重构：Mixin 目录拆为 entity/loot/rendering；弃用 @Redirect，改用 MixinExtras @Local 取局部变量降冲突。

🐛 修复：EntityClassInfo.create 加 try-catch，单个实体创建失败仅跳过不崩；NeoForge 注册、Modern UI 兼容等。

loot table/tempt 等昂贵计算。

DiscoveryStrategyMode（默认 VANILLA_KILL）热切换；DiscoveryEventListener 定义 8 种发现事件。剪影渲染走原版 outline 管线（entityRenderState.outlineColor = silhouetteColor，PictureInPictureRendererMixin 在 endBatch 后 flush）。
- Spawn 属性 + 结构解析：EntitySpawnManager 建 entity↔biome（遍历 MobSpawnSettings）、entity↔structure（spawnOverrides + Jigsaw）双向映射，对 JigsawStructure 用 BFS 遍历 startPool→fallback 全部 template pool；StructureTemplateIMixin/ListPoolElementIMixin 暴露
entityInfoList/palettes/elements。
- 描述组件：EntityDescriptionWidget 多 key 回退（<ns>.<path>.description/desc、lore.<ns>.<path>），0.5x 缩放双行。
- 命令：/biologydictionary config reload。

🔧 重构：落地 Session 生命周期体系（WorldSession/Client/ServerWorldSession 单例收纳进世界生/退世界灭的数据）；ConfigsUpdateCallback 实现 config 热更新自动重建；PlaceholderFallbackEntityRenderer 在渲染异常时退化为轮换头颅的 ArmorStand 占位。

## 3. 性能优化（可提炼成「加载更快、更省内存」的看点）

- 结构 / 模板解析提速：改用 ResourceManager + FileToIdConverter + NbtIo 直接读 .nbt，删除冗余 Mixin

- 耗时可控：entitySpawnAnalysisTimeoutSeconds（默认 6s），超时停止并产出空数据，避免卡顿
- 资源优化：材质改 blitSprite（sprite atlas）取代独立 PNG

## 4. 兼容与健壮性（可讲「更稳、不崩图鉴」）

### 4.1 渲染兼容

【1. 生物图鉴（Discovery）系统】

大家可以看到下面多了一个进度条，这是玩家发现生物的进度，已发现/所有。在创造模式下不太直观，切到生存你们就明白了（切）。可以看到未被发现的生物被显示为剪影，在每一种生物都需要你先去「发现」，才能解锁它的完整信息（点击生物打不开）。

“发现”的策略有三种：全部解锁（演示发现 100%）、原版击杀（演示原版统计数据）、生物辞典（演示文件夹 nbt），默认生物辞典。

“发现”有多种方式：...... 同时可以看到击杀一只未解锁生物会弹 Toast + 高亮。

回到图鉴主页（演示回主页展示总进度条），底下现在有一条总进度条，告诉你一共发现了多少种、还差多少——强迫症狂喜。

而且每一次发现都会被详细记录下来。点进某个生物，能看到你第一次是在哪儿发现它的——哪个维度、什么生物群系、坐标是多少、当时是什么天气，连现
实时间和游戏内时间都给你记着，相当于一本冒险日记。

【2. 实体概览界面】

以前想看某种生物的属性，你得先在世界里找到一只活的；现在不用了——在图鉴里点任意一种生物，就能直接看到它的全部属性（顺手展示一些），只不过编辑是无效的。

【3. 新增Widget】

然后讲一下新增的生物组件。

支持查看生物生成信息。现在辞典会告诉你，这种生物会在哪些生物群系、哪些结构里自然生成。比如它是出现在林地府邸、废弃传送门，还是某个特定的群系，都能给你列出来。这背后其实是模组去解析了原版的拼图结构（Jigsaw），可能会缺失一些硬编码的条目，支持 datapack（展示文件夹）。如果模组太多可能会分析很慢，可以在设置里调整超时或关闭本特性。

这里还有个相关的小属性——刷怪计数，告诉你这种生物算不算在刷怪上限里、属于哪个刷怪类别，对你做刷怪农场挺有用的。

现在还支持了生物描述，辞典会读取生物的描述文本展示在详情页。可以通过安装 Item Descriptions 或自己写材质包（展示文件夹）的方式来添加描述。

以及现在点击生物展示组件有音效，左键攻击、右键普通音效。类似于在抚摸。

【6. 模组兼容性】（略提）

最后是模组兼容性，这一版增强非常大。和其他模组的冲突修了不少（展示安装的模组）。
