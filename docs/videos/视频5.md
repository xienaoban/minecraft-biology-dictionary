# 生物辞典 1.3 大版本视频素材

> 目标：MC 26.3 的 1.3.x 版本；按玩家感知的重要性排序，不按版本顺序。

## 一句话总结

1.3 大版本 = 一个核心玩法（全服共享发现）+ 一套社交反馈（公告 / 排名 / 点击）+ 26.3 适配 + 若干便利与修复。

## 按重要性排序

### 1. 全服共享发现（核心，2–3 分钟）

**钩子：** 一个人发现，全服解锁。

- 服务端配置 `discoveryGlobalShared`，默认关闭，只在「生物辞典」策略下生效。
- 任意玩家发现某生物，全服所有人立即在图鉴里解锁；开启期间新加入的玩家直接继承进度。
- 纯视图共享：不往存档写额外数据；关掉开关就回落到各自的真实记录；支持运行时切换。
- 演示：双客户端，A 发现新生物 → B 的图鉴立刻亮起；关掉开关后 B 的图鉴回落。

**为什么排第一：** 1.3 最大的新玩法，也是多人服最有感知的变化，先讲它视频才有「更新了什么」的抓手。

### 2. 发现公告与社交互动（1–2 分钟）

**钩子：** 发现不再是静悄悄的事。

- 公告上限 `discoveryAnnouncementLimit`，默认 5；`-1` 不限，`0` 关闭。
- 前 N 名发现者全服公告；之后发现的玩家只收到自己的提示，防刷屏。
- 公告里的玩家名可点击建议 `/tell`，悬浮显示该玩家解锁数量；生物名可点击打开总览。
- 发现详情展示发现者、现实 / 游戏时间、方式、地点、天气；公告与提示显示「全服第 N 个发现该生物」。
- 没装模组的客户端收到原版聊天回退，不会静默失败。

**为什么排第二：** 共享发现的自然延伸，决定「共享」好不好玩；紧跟第一条最顺。

### 3. 26.3 支持（1–2 分钟）

**钩子：** 26.3 也能用了，而且适配得比较完整。

- 26.3 首发适配，Fabric / NeoForge 双端；1.3.1 起为正式版，1.3.2 为推荐版本。
- 战利品表跟进 26.3 新格式，掉落物显示正常。
- 刷怪数据补齐：骆驼尸壳、僵尸鹦鹉螺，以及袭击 / 结构相关生物。
- 修复鹦鹉食物显示。
- 底层属性解析跟进 26.3 的 NBT 变化（挑一两个直观例子，不报字段清单）。

**为什么排第三：** 对 26.3 玩家是「能不能用」的问题，但演示性不如共享发现；放在玩法之后，避免开场变成更新日志。

### 4. 新命令与快捷键（1 分钟）

**钩子：** 聊天栏直接开图鉴。

- `/biologydictionary overview <entity_type>`：从聊天栏直接打开生物总览。
- 新增「偷窃物品栏」快捷键，默认未绑定，提醒观众自行绑定。
- 各给一个镜头即可，不必展开。

**为什么排第四：** 有用但不是版本卖点，放在玩法之后、修复之前，节奏刚好。

### 5. 稳定性修复（30–60 秒）

**钩子：** 顺手修了一堆边角问题。

- NBT UUID 长度校验、坏掉的战利品 / 刷怪条目容错。
- 物品发放时的复制处理。
- JEI 子类型注册修复，辞典书在 JEI 里不再和普通书混在一起。
- 依赖版本跟进一句话带过。

**为什么排最后：** 观众对修复的耐心最低，但它能建立「这个版本靠谱」的印象；短平快最合适。

### 6. 一句话带过：内部重构

`Extract common codes`、`NbtUtils` 抽取、网络包合并、测试补充等，正片一句「底层重构和依赖更新」即可；开发日志向视频再展开。

## 3 分钟精简版

1. 共享发现演示（1.5 分钟）
2. 公告 / 排名（40 秒）
3. 26.3 支持 + 推荐 1.3.2（40 秒）
4. 结尾（10 秒）

## 拍摄清单

- 双客户端 + 服务端；服务端配置打开 `discoveryGlobalShared`。
- A 发现新生物 → B 的图鉴解锁、收到公告。
- 关闭开关 → B 的图鉴回落。
- 新玩家加入 → 直接继承进度。
- 公告点击玩家名 / 悬浮；点击生物名 / `/biologydictionary overview`。
- 26.3：展示掉落物、骆驼尸壳 / 僵尸鹦鹉螺刷怪信息、鹦鹉食物。
- JEI：辞典书子类型正常显示。

## 口径与事实备查

- 26.3 线只有 `v1.3.0-beta-mc26.3`（09-17）、`v1.3.1-mc26.3`（09-24）、`v1.3.2-mc26.3`（09-28），没有 1.3.0 正式版。
- 26.3 的 1.3.0 changelog 只写了 `Support 26.3!`；共享发现是 1.3.0 系列在 26.2 首发的，26.3 通过移植继承。视频里说「1.3 系列新增」更准确。
- 1.3.2 是 26.3 的推荐版本。
